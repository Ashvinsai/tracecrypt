# Requirements matrix

This matrix reports the repository's current implementation state, not planned work. `DONE` means the stated, bounded scope is implemented and has supporting tests or saved evidence; it does not imply production readiness or broader coverage. `PARTIAL` names both what works and what remains. `NOT BUILT`, `NOT CONFIGURED`, and `BLOCKED` are distinct non-delivery states.

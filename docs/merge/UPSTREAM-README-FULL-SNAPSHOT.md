# Crypto Attribution — full project snapshot

Complete source plus all recorded demo data, as of 27 September 2026.

**This snapshot includes work that is not yet committed to git** — a real Circle
CCTP V2 cross-chain bundle (Ethereum -> Base), two System-1 routing
shadow-validation bundles, a full React console (15 pages), and a read-only demo
API. If you rely on this, commit the work in your checkout too.

## Setup

```bash
cd api && uv sync && cp .env.example .env   # then set CFA_TRON_API_KEY
cd ../frontend && npm ci                    # optional; needed to rebuild the UI
```

## Run

```bash
make demo        # http://127.0.0.1:8010/investigator
make test        # test suite
make check       # lint + typecheck + test
```

Needs `make demo-prepare` once if `frontend/dist` is absent.

## Where to start reading

1. `AGENTS.md` — the binding rules. Read first.
2. `README.md` then `START_HERE.md` — what it does and refuses to do.
3. `docs/REQUIREMENTS_MATRIX.md` — honest DONE / PARTIAL / NOT BUILT status.
4. `docs/ACCEPTANCE_CATALOG.md` — every criterion mapped to a real test.
5. `data/verified_anchors.csv` — the two real OKX anchors. Read the `methodology`
   column; it is the single most important paragraph in the project.
6. `api/app/engine/tracer.py` — the tracing engine.
7. `var/live-validation/` — recorded real runs to read as worked examples.

A curated reading-only package covering just the files needed to understand the
design is also available separately.
